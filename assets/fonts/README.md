Place Montserrat Alternates font files here for offline usage.

Required filenames (used by pubspec.yaml):
- MontserratAlternates-Regular.ttf
- MontserratAlternates-SemiBold.ttf  (weight: 600)
- MontserratAlternates-Bold.ttf      (weight: 700)

How to obtain fonts:
- Montserrat Alternates is available on Google Fonts. You can download the family from:
  https://fonts.google.com/specimen/Montserrat+Alternates

After adding the files to `assets/fonts/`, run:

```bash
flutter pub get
flutter run
```
